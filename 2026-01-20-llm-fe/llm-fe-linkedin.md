Feature engineering is still one of the biggest time sinks in data science. That’s starting to change.

A new approach called LLM-FE pairs large language models with evolutionary optimization to generate features for tabular data automatically. Rather than asking an LLM for a one-off list of feature ideas, LLM-FE runs an iterative loop: features are tested against real model performance, the ones that work are kept, promising ideas are refined, and weak directions are dropped.

Across a range of datasets, this approach beats both traditional automated feature engineering tools and earlier LLM-based methods.

What this means for ML teams-

1. Feature engineering becomes much faster
2. More time shifts to problem framing, data quality, and validation
3. Interpretability is preserved, since every generated feature comes with inspectable code

This is worth paying attention to, especially as techniques like this make their way into mainstream AutoML platforms.
