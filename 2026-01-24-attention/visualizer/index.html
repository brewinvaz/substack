01 Tokenization

01 Tokenization

Input text is split into discrete tokens for processing

INPUT
The cat sat on the mat

02 Embeddings

Each token is mapped to a high-dimensional vector representing its semantic meaning

03 Query, Key, Value Projections

Each embedding is transformed into three distinct vectors through learned weight matrices

Query (Q)

"What am I looking for?"

Key (K)

"What do I contain?"

Value (V)

"What information do I carry?"

04 Attention Scores

Compute relevance between each Query and all Keys via dot product

Score[i,j] = Q[i] · K[j] / √dk
Query (rows) "What am I looking for?"
Key (columns) "What do I contain?"

KEY

05 Softmax Normalization

Convert raw scores to probability distribution (each row sums to 1.0)

Attention[i] = softmax(Scores[i])

06 Weighted Combination

Compute output as weighted sum of Value vectors based on attention weights

07 Contextual Outputs

Each token now carries contextual information from tokens it attended to

"sat" now encodes information about "cat" (the subject performing the action)

With causal attention, each token only sees previous tokens. "sat" strongly attends to "cat" (80%) to understand who is performing the action.
